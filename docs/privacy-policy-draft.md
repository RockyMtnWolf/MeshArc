## 二、功能及数据处理（按当前源码审计，需发行版复核）

1. **VPN 与 Tailscale 网络**：用户发起连接后，应用通过 native Go Tailscale 引擎建立用户态 VPN/TUN。为连接、路由、显示 peer/网络状态，设备会与用户所用 Tailscale 控制服务、DERP 或对端通信；IP、连接元数据、节点/peer 信息及认证信息可能由相应 Tailscale 服务处理。MeshArc 不应承诺这些数据只在本机处理。登录方式、控制服务器和实际传输/日志字段需按发行版本验证。
2. **FRP 远程访问**：用户启用 FRP 配置时，内嵌 FRP 客户端连接配置中的服务端并按代理规则转发流量。配置可含服务地址、用户名/令牌等凭据；目标服务、服务端运营者及其留存由用户配置决定。应用需要避免输出凭据到日志/诊断报告，并提供本地配置查看/删除方式（发行前确认）。
3. **文件传输**：Taildrop 可传输用户选定文件；LocalSend 兼容性功能会通过 Tailscale 网络探测 peer 的注册端点。处理的元数据可能包括 peer 名称/地址、文件名、大小、传输状态。收到文件可能暂存于应用私有目录；目前代码存在 inbox/outbox/cache 管理逻辑，具体留存期限和用户清理入口**待版本核实并补充**。不得声称会扫描整个设备文件。
4. **核心更新检查**：CoreUpdate 功能请求 GitHub Tailscale release/tag API 获取版本元数据。当前代码导出构建请求；界面注明自动下载、编译、签名和安装尚未实现。GitHub 可能收到常规网络连接元数据；MeshArc 当前不应描述为自动安装核心更新。
5. **诊断与本机状态**：应用记录 VPN/传输等诊断事件，并可生成诊断报告；报告含设备系统版本、网络/VPN状态等字段。分享由用户操作触发的设计需在发行版确认；报告可能包含可识别网络/peer信息，分享前应预览并脱敏。自动上传：**当前源码审计未发现诊断报告自动上传路径；提交前再以发行包验证**。
6. **权限及后台能力**：当前 manifest 声明 INTERNET、GET_NETWORK_INFO、GET_BUNDLE_INFO、KEEP_BACKGROUND_RUNNING、VIBRATE、ACCESS_BIOMETRIC；最后一项的必要性/调用尚待确认。应用含 VPN extension、statusBarView extension、`dataTransfer` 和 `audioPlayback` 后台模式。模拟下载模式不传输文件；音频模式循环播放本地合成低音量音频。此类模拟保活可能不符合商店后台能力审核，且有审核不通过风险；拟上架版本应移除或改为仅支持确有用户价值的进行中任务，并更新本政策/权限清单。
7. **入站 TCP 暴露**：共存功能可在 Tailscale 网络上桥接用户选择的 TCP 端口，亦有 allow-all 全端口开关。启用后 tailnet 上具备相应网络访问条件的设备可尝试访问本机对应服务；实际权限还受 Tailscale ACL 和目标服务认证约束。全端口选项风险更高，需默认关闭、明确提示、用户确认、可随时撤销，并在最终政策解释用途与风险。
